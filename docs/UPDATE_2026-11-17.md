# Test build update, 2026-11-17

- High Valuables uses small cash symbols on native and browser maps.
- Added a Ground Zero valuable-item category and independent web release.
- Backpack, vehicle-key and stash subfilters are available independently.
- Browser tracking can remember a selected player across temporary absence.
- Overlay enemy color is configurable; the crosshair ring is thinner.
- Overlay movement uses bounded prediction for short sampling gaps.
- Target detection uses projected regions derived from fresh skeleton samples,
  with optional region visualization and a bounded edge tolerance. These are
  conservative approximations, not verified engine collision volumes.
- Click output releases when its activation conditions stop being true and
  preserves a distinct button-up interval between repeated clicks.

The x64 application build, camera/geometry tests, Webmap JavaScript tests and
isolated browser fixture tests passed during implementation. The JavaScript
tests were also rerun before this update. Fixture results do not establish
live DMA accuracy. The latest body-region detection still requires testing
against actual game targets, scopes and movement on the two-PC setup.

Runtime configuration, compiled binaries and tunnel credentials are excluded.
