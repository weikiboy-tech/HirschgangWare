# Confirmed test version, 2026-11-18

- Primary and optional Secondary trigger bindings have separate input sources
  and combine with OR semantics. Either keyboard or mouse on either PC can
  supply a binding. Escape cancels capture, preserves the old binding and is
  never a valid bind. Clear removes one slot. Existing primary INI values
  retain their meaning.
- Green friends remain rendered but are excluded from the trigger candidate
  list. Overlapping opponents can still be selected; this is not occlusion.
- Chest and abdomen envelopes are approximately 17% wider; other body regions
  and pixel tolerance remain unchanged. These approximate skeleton-derived
  regions are not the game's engine collision volumes.
- Player identities are resolved from fresh IDs, with duplicate detection and
  validation of roster rows. The web protocol reports whether names are
  released. The local test's PlayerNames release was enabled explicitly;
  production host release controls remain intact.
- High Values uses 12 listed sellable classes above 50,000 maximum trader sale
  value, plus the existing Bitcoin recognition rule. Cheaper and exactly
  50,000-value items, weapons, armor and building items are excluded. Bitcoin
  has its own icon. Prices are the documented November 2 trader snapshot.
- Special ground loot includes Duffel bags, hidden stashes and supported safes,
  with a 1,000 m overlay minimum. Both maps share the collected snapshot.
  This cannot extend client object replication or discover unknown mod types.
- The WebRadar hides its map behind a Hirschgang connection screen without
  valid live data and restores it after reconnect, retaining preferences.

The full MSVC x64 build and final changed-source recompilation passed. The
camera/input suite checks independent sources, simultaneous holds, all five
mouse buttons, reconnect baseline, Escape/capture, configuration round trips,
geometry, friends and UDP click output using synthetic input and loopback.
JavaScript and isolated browser tests passed for web markers, host releases,
waiting screen, reconnect and desktop/mobile layout.

The user confirmed the current two-binding behavior works on their setup.
This report does not establish live correctness of all scopes, player-name
offsets, server-specific safe classes or 1,000 m object availability.
Runtime configuration was backed up locally under the ignored build directory;
personal INI files and credentials are not included in this commit.
